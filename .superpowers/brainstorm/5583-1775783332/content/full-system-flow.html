App Launch Flow

GoRouter Redirect Chain
// Existing
App Opens → Splash → Is authenticated?
├─ No → Auth Landing
├─ Yes, first time → Onboarding → Security Setup Prompt (NEW) → Dashboard
// New lock check (after auth)
└─ Yes, returning → Is PIN set & app locked?
├─ Yes → PIN Lock Screen (NEW) → Verify → Dashboard
└─ No → Dashboard

Privacy Masking Flow

Eye Icon Toggle Behavior
User taps 👁 eye icon in app bar
Currently VISIBLE → wants to HIDE:
└─ Mask immediately (no auth needed)
└─ All amounts → ****
Currently HIDDEN → wants to REVEAL:
├─ No PIN set → Unmask immediately
└─ PIN set:
├─ Already verified this session → Unmask immediately
└─ Not verified → PIN / Biometric prompt → Unmask
// Session resets when app backgrounds >30s

Nudge System

Maximum 2 Touchpoints, Then Silent
Touch 1: Post-onboarding security step
├─ "Set up PIN" → PIN setup → done, no more nudges
└─ "Skip for now" → flag saved
Touch 2: Dashboard banner (once, after first tracker data)
├─ "Set up" → Settings → PIN setup → done
└─ "Dismiss" → flag saved, never again
// After both: feature lives in Settings → Security
